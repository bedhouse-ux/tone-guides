01
Create a GitHub Account
github.com → Sign up
Go to github.com and create a free account if you don't have one. Your username becomes part of your site's URL, so choose something you're comfortable with being public.
Your future URL

Once set up, your site will live at https://yourusername.github.io/tone-guides — permanent, free, no expiry.

02
Create a New Repository
github.com → + → New Repository
A repository is just a folder on GitHub that stores your files. Click the + icon in the top right → New repository. Fill in the fields as follows:
Settings
Repository name:  tone-guides
Description:      Guitar tone guides (optional)
Visibility:       Public          ← required for free Pages
README:           Leave unticked
Why Public?

GitHub Pages on a free account requires the repository to be public. This just means the HTML files are viewable — it's no different from a normal website. Your tone guide content isn't sensitive.

03
Upload Your HTML Files
Repository → Add file → Upload files
Inside your new repository, click Add file → Upload files. Drag and drop all your tone guide HTML files. You don't need any special folder structure — flat is fine.
Repository structure
📁 tone-guides/
📄 index.html ← landing page (we'll add this in step 5)
📄 glory-box-tone-guide.html
📄 fell-on-black-days-tone-guide.html
📄 black-keys-tone-guide.html
📄 khruangbin-tone-guide.html
📄 ... (all other guides)
After dragging the files in, scroll to the bottom and click Commit changes. The default commit message is fine.
File Names Matter

Keep filenames lowercase with hyphens — no spaces or special characters. Your existing files already follow this convention. Each filename becomes part of the URL, e.g. glory-box-tone-guide.html → /glory-box-tone-guide.

04
Enable GitHub Pages
Repository → Settings → Pages
In your repository, click the Settings tab (top right of the repo). In the left sidebar find Pages. Under Build and deployment, set:
Pages Settings
Source:  Deploy from a branch
Branch:  main
Folder:  / (root)
Click Save. GitHub will now start building your site. This takes 1–3 minutes the first time.
Confirmation

Refresh the Settings → Pages screen after a minute. You'll see a green banner: "Your site is live at https://yourusername.github.io/tone-guides". That's your permanent URL.

05
Add an Index Page
Optional but recommended
Without an index.html, visiting your root URL shows a raw file listing — functional but ugly. An index page acts as a styled home screen listing all your guides as cards. I can build this for you — it will match the dark aesthetic of your existing guides and auto-link to each file.
What the index page gives you

A single URL you can bookmark or share — yourusername.github.io/tone-guides — that shows all your guides as a visual grid. Artist name, guitar, rig metadata, and a link to each guide. Matches the existing visual language exactly.

Once I build it, upload it to the repository the same way as Step 3 — drag, drop, commit. GitHub Pages will update automatically within about 60 seconds of any new upload.
06
Updating Guides Later
Repository → Add file → Upload files
Adding or updating guides is the same process every time — upload the new HTML file to the repository, commit, and it's live within a minute. No build step, no command line required. GitHub Pages deploys on every commit automatically.
Update workflow
1.  Open  github.com/yourusername/tone-guides
2.  Click  Add file → Upload files
3.  Drag the updated .html file
4.  Click  Commit changes
5.  Wait ~60 seconds → live
Replacing an existing file

If you upload a file with the same name as an existing one, GitHub replaces it automatically. No need to delete the old version first.
